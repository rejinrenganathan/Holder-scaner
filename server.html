Server setup

One-time setup, about 10 minutes on your phone.
This creates the Holder Scan server (accounts and sign-in) on your Cloudflare account. It is separate from your current webhook Worker, which keeps running as it is.
1Create the database
  1. Open dash.cloudflare.com and log in.
  2. Go to Storage & Databases → D1 → Create database.
  3. Name it holderscan-users → Create.
2Create the Worker
  1. Go to Workers & Pages → Create → Create Worker (Hello World).
  2. Name it holder-scan-api → Deploy.
3Connect the database to the Worker
  1. Open the holder-scan-api Worker → Settings → Bindings → Add → D1 database.
  2. Variable name: DB (capital letters) · Database: holderscan-users → Save / Deploy.
4Paste the server code
  1. Tap Copy server code below.
  2. In the Worker, tap Edit code, select all the old code, delete it, paste, then Deploy.

5Connect the app
  1. Copy the Worker's address — it looks like https://holder-scan-api.yourname.workers.dev.
  2. Open the Account page, paste it, tap Connect.
