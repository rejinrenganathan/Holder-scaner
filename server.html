Server setup

One-time setup, about 10 minutes on your phone.
This creates the Holder Scan server (accounts and sign-in) on your Cloudflare account. It is separate from your current webhook Worker, which keeps running as it is.
1Create the database
  1. Open dash.cloudflare.com and log in.
  2. Go to Storage & Databases → D1 → Create database.
  3. Name it holderscan-users → Create.
2Create the Worker
  1. Go to Workers & Pages → Create → Create Worker (Hello World).
  2. Name it holder-scan-api → Deploy.
3Connect the database to the Worker
  1. Open the holder-scan-api Worker → Settings → Bindings → Add → D1 database.
  2. Variable name: DB (capital letters) · Database: holderscan-users → Save / Deploy.
4Paste the server code
  1. Tap Copy server code below.
  2. In the Worker, tap Edit code. Long-press in the code → Select all → delete, until only line 1 is left and it's empty.
  3. Long-press → Paste. Check the last line number matches the number shown below, and the bottom bar shows 0 errors.
  4. Tap Deploy.
Updating the server later? Do this same step again with the new code.
Loading the code…
5Connect the app
  1. Copy the Worker's address — it looks like https://holder-scan-api.yourname.workers.dev.
  2. Open the Account page, paste it, tap Connect.
Go to Account
6Open your owner dashboard
  1. Your dashboard lives on the server's own address: add /owner to the end, e.g. https://holder-scan-api.yourname.workers.dev/owner.
  2. Open it inside Phantom's browser (or tap Open in Phantom on that page) and sign in with your owner wallet.
  3. Bookmark it. It's not linked from the public site.
Google sign-in: once you've created a Google sign-in ID, paste it in Site control → Owner access, together with your Gmail.
★Auto-update the server (no more pasting)
One-time. After this, every server update deploys by itself.
  1. Make a token: Cloudflare → profile icon (top right) → My Profile → API Tokens → Create Token → template Edit Cloudflare Workers → Use template. Under Account Resources pick your account → Continue to summary → Create Token. Copy it (it's shown once).
  2. Account ID: Cloudflare → Workers & Pages → Overview. The Account ID is on the right side (or bottom on phones). Copy it.
  3. Database ID: Cloudflare → Storage & Databases → D1 → holderscan-users. Copy the Database ID.
  4. Open GitHub → New repository secret and add three secrets, one at a time (Name exactly as written, then paste the value, then Add secret):
    CLOUDFLARE_API_TOKEN · CLOUDFLARE_ACCOUNT_ID · D1_DATABASE_ID
  5. Tell Claude it's done — the first auto-deploy will be checked from here.
The token can only edit Workers on your account. Never paste it anywhere else. You can delete it in Cloudflare any time.
7Turn on visitor counting
Send your server address to Claude. It gets added to the site pages so every visit is counted for Traffic (no cookies, IDs change daily).
